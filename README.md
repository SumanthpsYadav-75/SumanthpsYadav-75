My goal is to reduce manual configuration and make infrastructure deployment more consistent and repeatable.<br><br>I am also learning containerization and application deployment using Docker. I understand how to build Docker images, write Dockerfiles, run containers, manage volumes and networks, and use Docker Compose to organize multi-container applications. I use Git and GitHub to manage source code, track changes, maintain repositories, and understand collaborative development workflows.
